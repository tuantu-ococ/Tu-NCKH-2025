eye-tracker-demo-v2

Run:
1. unzip and open folder in VSCode
2. npm install
3. npm run dev
4. open http://localhost:5173 and allow camera
5. Click "Bắt đầu" to start; calibration 12 điểm will run automatically.
6. Look at each calibration dot and click it. After calibration you will see an accuracy score and gaze cursor.

Notes:
- Ensure camera permission is granted.
- Do calibration in good lighting and keep head relatively still for best results.
